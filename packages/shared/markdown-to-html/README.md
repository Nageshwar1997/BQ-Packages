# @beautinique/shared-markdown-to-html

Shared Markdown file to HTML file generation for Beautinique.

## Installation

```bash
npm install @beautinique/shared-markdown-to-html
```

## Usage

```ts
import {} from '@beautinique/shared-markdown-to-html';
```
