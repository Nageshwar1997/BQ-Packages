# Beautinique Packages

A collection of reusable TypeScript packages used across the Beautinique ecosystem.

## Packages

### Shared

* Constants
* Types
* Utilities
* Zod Schemas

### Backend

Reusable backend libraries for Node.js services.

### Frontend

Reusable frontend libraries for React applications.

## Requirements

* Node.js 24+
* npm 11+
